# Consolidated GitHub package — release notes (2026-10-25)

## Changes in this cleanup

- Standardized the current experiment naming to E1–E6; **E5-B** remains mentioned only where explaining historical naming.
- Replaced obsolete `SMPM_revised` repository-name references in **comments only**.
- Kept one canonical E4 corrected figure source, `plot_E4_from_saved_results.R` (previously `E4_figure_corrected_final.R`), removing the redundant alternative script. The archived corrected figure was not regenerated.
- Rewrote the root README; added an E1–E6 experiment index, a read-only R syntax check, and hashes for archived results.
- Retained historical `SOURCE_MANIFEST.csv` unchanged, including original filenames, as a provenance record.
- Did **not** change any archived results, rerun Monte Carlo, or create an unprovided license or DOI.

## Verification boundaries

- The included Python read-only checker verifies E4/E5/E6 CSV consistency, not all RDS objects or E1–E3 raw statistics.
- R source parsing requires an R installation. No claim of successful full R execution is made.
- Simulation entry points write to `results/`; do not run them inside the archival copy.
- No guarantee is made that every archived output was generated by the current revision of the simulation code.
