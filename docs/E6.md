# E6 — Localized phenotype-associated signals

Formerly labeled E5-B in earlier working archives. All current scripts and result filenames use **E6**.

## Scientific design

Three compact-support signal geometries (broad, narrow, adjacent), five event types, three equally likely phenotype groups, n=500, depth D=50/200/1000, and B=500 repetitions. Compare direct SMPM, fixed trigonometric smoothing, and ten-bin reconstruction on the same simulated realization. Evaluate with W=20 and W=40 windows per event type.

## Rotation-invariant localization score

For event type r and evaluation window j, the discrete vector total-variation score is

S[r,j] = sum over increments ell in window j of sqrt(sum over k=1,2 of (phi[k,r](t[ell+1])-phi[k,r](t[ell]))^2).

**The square root is inside the sum over increments.** This agrees with Eq. (36) in the manuscript, the corrected Eq. (S5) in the SI, and the `window_tv()` implementation.

An active event-type/window pair has positive-length overlap with the analytic contrast support. For W=20, active counts are broad=26, narrow=14, adjacent=18; for W=40 they are broad=44, narrow=18, adjacent=28. AP, oracle top-K F1, Spearman, and minimum canonical cosine are summarized. The oracle top-K uses K equal to the true number of active entries.

## Reproduction (computationally expensive)

Run from the repository root in separate clean R sessions, using the same random seed for each evaluation resolution:

```r
Sys.setenv(SMPM_E6_B='500', SMPM_E6_WINDOWS='20')
source('run_E6.R')
```

Then restart R and run with `SMPM_E6_WINDOWS='40'`. For a quick smoke test, use `SMPM_E6_B='3'`, but **do not overwrite the archived B=500 results**. Prefer a copy of this repository for new runs.

The variable names `SMPM_E5B_*` were changed to `SMPM_E6_*` in the code. This is a naming change, not a reanalysis.
